Where to find the event fields

Inspect the test checkout’s destination event. Collect only its transaction ID, numeric value, currency and, for Ads, the observed conversion action. Replace the example values with what you actually observed.

GA4 purchase

In GA4 DebugView, select the test device and open the purchase event to inspect its parameters.

{"name":"purchase","params":{"transaction_id":"DEMO-1001","value":45,"currency":"USD"}}

Google Ads conversion

In a connected Tag Assistant session, inspect the Google Ads conversion tag for the test checkout. Use the observed Ads ID and action label together in send_to.

{"send_to":"AW-123456/example","transaction_id":"DEMO-1001","value":45,"currency":"USD"}

Use redacted JSON. If you redact transaction IDs, preserve whether the original IDs match. Omit client IDs, email addresses, phone numbers, API secrets and cookies.
